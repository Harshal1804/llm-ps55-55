# Fitness Routine Planner

An AI-powered Fitness Routine Planner built using Python, Streamlit, and Google's Gemini API.

## Problem Statement
PS55 – Fitness Routine Planner

## Features
- Generate personalized 7-day fitness routines.
- Choose fitness goals: Weight Loss, Muscle Gain, General Fitness, and Flexibility.
- Customize plans based on fitness level and available daily time.
- Select available workout equipment.
- Specify injuries or physical limitations.
- View exercises with sets, repetitions, duration, and rest intervals.
- Get warm-up, cool-down, form tips, and recovery recommendations.
- Download the generated workout plan as a CSV file.

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Google Gen AI SDK
- Pandas
- Python dotenv
